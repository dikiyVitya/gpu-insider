GPU INSIDER — цвет кнопок и подробная страница

В архиве обновлены:
- script.js
- style.css
- data/gpus.json

Установка:
1. Сделай резервную копию своего проекта.
2. Замени этими файлами одноимённые файлы в проекте.
3. Не удаляй index.html и папки assets — изображения и логотипы остаются в твоём проекте.
4. Запусти через Live Server и обнови страницу Ctrl+F5.

Что изменено:
- Кнопка «ПОДРОБНЕЕ» зелёная для NVIDIA и красная для AMD.
- Цветовые акценты подробной страницы также меняются по выбранному GPU-вендору.
- Страница MSI GeForce GTX 1660 SUPER Gaming X расширена: общие сведения о GPU, характеристики чипа и конкретной платы, охлаждение, источники.
- Добавлены ссылки на официальные страницы NVIDIA и MSI.

Важно:
В текущей базе заполнена ветка NVIDIA. Для AMD цветовая схема уже предусмотрена, но сами карточки AMD появятся после добавления проверенных моделей в data/gpus.json.
Характеристики без подтверждения не подменяются догадками: для них выводится «Уточняется».
